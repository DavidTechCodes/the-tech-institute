# Tech Institute

A modern technology academy platform focused on providing engaging digital learning experiences through clean, intuitive, and responsive interfaces.

Tech Institute is currently being developed with a **frontend-first approach**, with a primary focus on UI/UX design and React development. The project explores the design and implementation of a modern platform for technology courses and learning resources.

## 🚀 Project Overview

Tech Institute is designed as a digital academy where learners can explore technology-related courses and learning content through a modern web interface.

The current development phase focuses primarily on the frontend experience, including:

* Modern and responsive user interfaces
* Course discovery and presentation
* Intuitive navigation
* Learning-focused user experiences
* Reusable React components
* Responsive layouts for different screen sizes
* Clean and maintainable frontend architecture

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/DavidTechCodes/tech-institute.git
```

Navigate into the project:

```bash
cd tech-institute
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.
